# GCP

## 一、接入层（Front Door / Edge / Ingress）

> **用户、设备、第三方系统进入云的第一道门**

### 核心目标

- 流量入口统一
- 安全防护
- 协议与身份标准化

### GCP 产品

- API Gateway
- Endpoints
- Apigee（API Management）
- Firebase Hosting
- Cloud Run（公网入口）
- App Engine（公网应用）
- Google Maps Platform（对外能力）
