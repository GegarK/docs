# WINDOWS 开发

## 什么是 WINDOWS 开发

WINDOWS 编程就是程序员开发编译的程序可以在 WINDOWS 环境下运行。

## WINDOWS 编程开发语言

- C#
- VB
- JAVA
- C/C++
- GOLANG

## 什么是 WINDOWS SDK、API 是什么

WINDOWS SDK（Software Develope Kit - 软件开发工具包），它包含了进行 WINDOWS 软件开发的文档和 API（Application Programing Interface）函数的库文件。

## Modal Dialog Box

用户必须点击操作的窗口。

## CUI && GUI

GUI and CUI are two types of User Interfaces. GUI stands for Graphical User Interface while CUI stands for Character User Interface.
